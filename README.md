# WZTI · 王者人格研究所

手机优先的《王者荣耀》同人趣味人格测试。28 道生活问题、七个偏好维度、128 种英雄结果、原创程序化低多边形矢量插画、PNG 人格名片、结果分享、答案本机保存。元流之子合并为一个人格，同时展示男女形象。

## 使用与发布

纯静态 HTML/CSS/JavaScript，无需安装依赖或配置 API 密钥。下载后打开 index.html 即可使用，或用任意静态服务器托管此目录。

GitHub Pages 发布：仓库 Settings → Pages → Build and deployment → Source 选择 **GitHub Actions**，然后在 Actions 中运行 **Publish WZTI**，或向 main 推送修改。成功后访问 https://lyqien.github.io/wzti/ 。没有成功部署之前，此地址不表示已上线。

网站无服务器依赖，无外部字体、图片或脚本请求；角色插画全部由本地 SVG 绘制。点击资料出处时才访问外部网站。GitHub Pages 在中国大陆的连接质量取决于运营商和地区，不能保证所有用户均可访问；需要稳定面向大陆服务时，可将同一套静态文件迁移到国内静态托管与域名。

## 匹配算法

7 个维度，每个维度 4 道题，每题五档回答（1–5），包含反向计分。计算维度均值，再与英雄创作画像计算平方欧氏距离。完全相同时按英雄 ID 稳定排序；相似人物展示第二、第三名。画像大类相同的英雄使用 0.25 的小幅细分偏好，不使用随机抽签，不设置虚假的匹配百分比。所有 128 种结果在可回答的离散网格上均可达。

问题、英雄画像、性格解读与插画均为娱乐创作，无科学效度，不代表官方设定。测试不收集姓名、账号或答案；浏览器 localStorage 仅保存本机进度。分享链接只包含英雄编号。

## 资料与署名

英雄名录与背景参考腾讯《王者荣耀》[官方英雄资料](https://pvp.qq.com/web201605/herolist.shtml)，核对日期 2026-10-31。原接口 133 条，排除特殊条目心魔六耳，将五个元流之子分路合并，得到 128 种结果。官网接口的收录与游戏正式服可选状态未必同步，不将此数量宣传为正式服实时人数。

每位英雄的资料和台词来源位于 heroes.js 的 source、quoteSource、quoteKind 字段，页面可直接查看。短台词主要参考最趣分享逐英雄台词整理页；补充参考游侠手游、17173 等。部分台词可能属于皮肤语音，已按来源标注；盾山使用官方故事摘句，不伪造人声台词。没有下载或转载语音文件、原画、完整故事与整套台词。

插画为原创程序化低多边形同人表达，提炼英雄配色、发型、服装与装备特征，未使用 MBTI/16Personalities 官网人物图片。人物辨识细节仍可继续精修，不等同游戏原画。王者荣耀人物名称、设定等权利归各权利人所有。本站与腾讯、MBTI、16Personalities 无关联，免费、无广告。
